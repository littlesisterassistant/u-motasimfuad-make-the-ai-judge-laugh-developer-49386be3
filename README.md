# Make the AI Judge Laugh: Developer Excuses

One funny single-line excuse a developer gives when code breaks in production.

`main.ts` (Node 22, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), validates it is 1 to
200 characters and not only whitespace, reads the file back to verify the
write, and prints the line with its character count.

The line:

> The tests passed, the review passed, the deploy passed. Production is the only one that failed the vibe check.

Run it with `node main.ts`.
